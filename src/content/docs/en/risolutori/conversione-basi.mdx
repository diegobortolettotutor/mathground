This tool converts an integer between any two bases, from **2** to **64**,
showing each time the correct method for the chosen pair of bases: **positional
expansion** (towards base 10), **successive division** by the target base (from
base 10), **4-bit grouping** for direct conversion between base 2 and base 16,
or **bridging through base 10** for any other pair of non-decimal bases. In
every case the coefficients that multiply the powers of the base are
highlighted, to make the link between the digits of the starting number and
the calculation that uses them immediately clear.
