This tool converts an integer between **base 2**, **base 10** and **base 16**,
showing each time the correct method for the chosen pair of bases: **positional
expansion** (towards base 10), **successive division** by the target base (from
base 10), or **4-bit grouping** for direct conversion between base 2 and base
16. In every case the coefficients that multiply the powers of the base are
highlighted, to make the link between the digits of the starting number and
the calculation that uses them immediately clear.
