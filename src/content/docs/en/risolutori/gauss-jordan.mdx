An interactive tool to reduce a matrix to row echelon form (REF)
and reduced row echelon form (RREF).\
First set the matrix dimensions and cell values —
fractional (3/7) and symbolic (9-k) entries are also supported. Then choose between the
quick result or the detailed step-by-step solution with commentary.
