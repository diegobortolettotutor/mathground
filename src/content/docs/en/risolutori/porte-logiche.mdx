Given one or two binary words of $4$, $8$, $12$ or $16$ bits, this solver applies a
logic gate **bitwise**, chosen among BUFFER, NOT, AND, OR, NAND, NOR, XOR and XNOR.
The BUFFER and NOT gates have a single input $A$; all the others have two inputs
$A$ and $B$. The output is denoted by $Y$.

The step-by-step solution recalls Boolean logic, presents the symbol and the truth
table of each gate, and derives the output word $Y$ column by column, each time
reading the corresponding row of the truth table.
